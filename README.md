# Todo List - C++

A simple command-line To-Do List application developed in C++.

## Features

- Add a new task
- View all tasks
- Delete tasks by title
- Track whether a task is completed or not completed

## Data Structure

The project uses a linked structure where each task contains:
- Task title
- Completion status
- Pointer to the next task

## How to Run

```bash
g++ todo_list.cpp -o todo_list
.\todo_list.exe
```

## Menu

1. Add Task
2. View Tasks
3. Delete Task
4. Exit
